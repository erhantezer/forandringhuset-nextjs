# Forandringhuset – Next.js website

Tesla-inspired, full-screen responsive landing page built with Next.js App Router, JavaScript, CSS and Lucide icons.

## Start

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Notes

- The photos are demo images loaded from Unsplash and require internet access.
- Copy and contact information are placeholders: confirm with Forandringhuset before publishing.
- The layout is an original design inspired by Tesla's visual style, not a copy of Tesla's website.
